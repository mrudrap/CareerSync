PRIVATE GMAIL CONNECTION

Gmail sync setup

CareerSync asks Gmail only for read-only access to job-application messages. It stores parsed candidates and Gmail message IDs locally, not email bodies or OAuth tokens.

How to create the Google OAuth client
  1. Create a Google Cloud project and enable the Gmail API.
  2. Configure the OAuth consent screen and add student test users while the app is in testing.
  3. Create a Web application OAuth client.
  4. Add this dashboard’s HTTPS origin to Authorized JavaScript origins.
  5. Paste only the client ID here, never a client secret.

Before student use: publish over HTTPS and provide clear consent and retention notice. A production program should use a reviewed backend for encrypted storage and token handling.
